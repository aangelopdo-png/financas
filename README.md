# Finanças Angelo — pasta para publicar

Suba TODOS os arquivos desta pasta em um site estático com HTTPS (GitHub Pages, Cloudflare Pages ou Netlify).
Não há dados pessoais aqui: os lançamentos ficam no aparelho de quem usa.

Depois de publicado, abra o endereço no Safari do iPhone → Compartilhar → Adicionar à Tela de Início.
O app passa a abrir mesmo sem internet.

Para atualizar: rode `node build-deploy.js` na pasta Financas e suba a pasta de novo.
